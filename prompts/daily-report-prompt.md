# daily-report-prompt — 리포트 생성 프롬프트 (파이프라인 소스)

이 레포는 Python/JS 크롤러 대신 **Claude Code가 직접 수집·작성하는 AI-네이티브 파이프라인**이다.
전통적 코드의 역할을 이 프롬프트가 대신한다. 스케줄러(매일 08:00)가 아래 프롬프트를 실행한다.

## 실행 프롬프트

```
오늘 날짜 기준 글로벌 AI 동향 리포트를 생성해라.

1. WebSearch 5회 실행 (각 섹션별):
   - 신규 AI 모델 출시 / 기술 발표
   - 기업 AI 도입 통계·에이전틱 AI 트렌드
   - EU·미국·중국 AI 규제 동향
   - AI VC 투자·대형 라운드
   - 오늘의 핵심 단일 토픽 (딥다이브용)

2. 검증 규칙 (SOUL.md 판단 원칙 준수):
   - 모든 카드 링크는 원출처(공식 발표·원본 기사)만 사용
   - 2차 요약 블로그·범용 목록 페이지 금지
   - 수치·날짜·인명은 WebSearch로 교차 확인

3. HTML 생성:
   - 파일명: reports/AI_Report_YYYY-MM-DD.html
   - 구성: 상단 통계카드 4개 → 핵심 다이제스트 6건 →
     섹션 4개(모델&기술 / 기업AI도입 / 규제&정책 / 투자&시장) →
     딥다이브 1편 → 전략 시사점 5개 → 출처 목록
   - 라이트 테마(#f0f2f8), 카드 클릭 시 원문 이동, 당일 뉴스에 NEW 배지
   - 푸터에 자동 생성 명시

4. 생성 후: git add → commit → push
```

## 산출물 규칙

- 산출물은 `reports/` 폴더에만 누적한다 (루트 커밋 금지)
- 품질 점검은 `audit-and-issue` 스킬로 수행한다
